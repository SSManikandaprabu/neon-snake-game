# Neon Snake — Arcade Retro Game

A modern re-imagination of the classic Snake arcade game featuring glowing neon graphics, smooth canvas physics, and touch gesture controls.

## Features

- Vibrant glowing neon vector graphics rendered on HTML5 Canvas
- **Multiple gameplay modes**: Multiple gameplay modes: Classic (with border collision) and No-Walls (wrap-around screen)
- Dynamic score tracking, food combos, and high score persistence via LocalStorage
- **Fluid responsiveness**: Fluid responsiveness: responsive touch swipe controls for smartphones and Arrow/WASD keys for desktop
- Visual game over screen with instant restart
- Audio sound effects for eating food and collision game over

## Tech Stack

- HTML5 Canvas API
- CSS3
- JavaScript (ES6+)
- LocalStorage API
- Web Audio API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/neon-snake-game.git
   cd neon-snake-game
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `neon snake index.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/neon snake index.html](http://localhost:8000/neon snake index.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for Neon Snake — Arcade Retro Game.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.
